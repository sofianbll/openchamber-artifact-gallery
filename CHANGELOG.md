# Changelog

## 0.2.0 — 2026-10-28

First standalone public release.

- Contextual Session, Project/Chats and All scopes with a space explorer.
- Dated groups, source details and provenance-only composer attachments.
- Reopening attachment chips through the host bridge.
- Paginated metadata, two concurrent reads and at most six active thumbnails.
- Persisted preview, density, page-size, refresh and language preferences.
- English/French UI with host locale inheritance and an explicit override.
- Native semantic text sizes, embedded Geist Sans and host theme/radius tokens.
- Prebuilt archive, checksum, synthetic screenshots and static documentation site.

Known limits: host interface scale/padding are not exposed by SDK 2.5.2; external
fonts may fall back. Local host only. See the guide for complete boundaries.

## 0.1.0 — 2026-10-28

Local prototype integration: history collection, source index, native HTML
previews, filtering and source-session navigation. Not publicly distributed.
