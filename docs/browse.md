# Find an artifact

## Choose how far to look

| Scope | What you see |
| --- | --- |
| **Session** | Artifacts from the active conversation. A new conversation starts empty. |
| **Project / Chats** | Artifacts in the active conversation's space. |
| **All** | Projects, managed Chats and identifiable sources with no known space. |
| **All projects** | Project sources only, excluding Chats and unknown spaces. |

![The gallery explorer inside OpenChamber](assets/host-gallery.png)

The full page has a space explorer. In the side panel or a narrow window, select
**All**, then **Explore** to choose a space. An unknown folder is never treated as Chats.

## Search, filter and browse by date

Search by title or source conversation, then use the type filter to narrow results
to pages, images, tables or documents. Dates and times use your device's timezone.
The view shows 12 cards per page by default; choose 24 in gallery Settings.

Pagination replaces the visible cards. It does not append an ever-growing list.
No matches? Clear the filters or widen the scope before refreshing.

## When you change conversation

Your chosen scope stays selected. The search, type filter, page and expanded preview
reset. If you explicitly selected a space under **All**, that space stays selected.

The **Add to draft** destination follows the active conversation, not the space
you are exploring. [Learn how references work](reuse.md).

## Keep the index current

Opening the gallery requests a scan. While visible, automatic refresh checks for
changed sessions roughly once a minute. Use **Refresh** after creating a new artifact.
You can turn periodic refresh off in gallery Settings; a scan already running may
still finish. Failed source reads preserve existing references.
